# Energy Eye ⚡

## Energy Monitoring System

Energy Eye is a wireless energy monitoring project designed to measure electrical energy consumption in real time and transmit the measured data from a transmitter to a receiver for monitoring.

### Main Objective

Measure electrical energy usage, transmit the measurements wirelessly, receive the data reliably, and provide a simple serial-monitor interface for monitoring.

### System Flow

`Energy Sensor → Transmitter → Wireless Link → Receiver → Serial Monitor`

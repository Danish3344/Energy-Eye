# Components

This document records the hardware used by the Energy Eye project.

## Core Hardware

- Microcontroller for the transmitter
- Microcontroller for the receiver
- Electrical energy/current sensing hardware
- Wireless communication modules
- Jumper wires and breadboard/prototyping hardware
- USB connection for programming and serial monitoring

## Final Configuration

The exact component models, ratings, pin assignments, and sensor specifications will be documented here once the final hardware configuration is frozen.
